# 🍕 Python Restaurant Management System

A interactive command-line Python application that simulates a restaurant ordering system using loops, dictionaries, and user inputs.

---

## 🚀 Features

* **Dynamic Menu Display:** Displays available menu items with their respective prices.
* **Unlimited Ordering:** Uses a `while` loop allowing customers to add multiple items until they choose to finish.
* **Automatic Case Handling:** Handles user input effortlessly using `.title()` and `.capitalize()`.
* **Summary Bill:** Generates an itemized bill with total price calculation.
